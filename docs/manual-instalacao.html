💡 Antes de começar O instalador não instala Zabbix nem Grafana — eles devem estar instalados e rodando no servidor (premissa: o script cuida só do Downdetector). Você vai precisar de acesso root/sudo, das credenciais da API do Zabbix e do admin do Grafana.

3 Como o sistema funciona

O monitor não mede a rede — ele mede o que o Downdetector BR reporta publicamente sobre cada serviço. O pipeline tem 4 elos:

  1. Coletor Python

    Abre a homepage do Downdetector BR num Chromium real (Xvfb + patchright, que passa no Cloudflare) e extrai o status dos 42 serviços.

  2. zabbix_sender → Zabbix

    Envia o status de cada serviço para o host Downdetector (85 itens criados por LLD) a cada 5 minutos, via cron.

  3. Grafana

    Dois dashboards NOC leem o Zabbix: o Wallboard para a TV e o User para acompanhar no navegador.

  4. Verificação automática

    O heartbeat detecta coleta parada há mais de 15 min; a instalação só termina depois de 10 checks verdes.

Status enviadoO que significa no dashboard
0 — OKSem problemas reportados no Downdetector.
1 — InstávelServiço aparece no Top Reclamações. Amarelo há menos de 1 h; vermelho a partir de 1 h.
2 — CríticoUm problema severo — laranja quando recente.
-1 — Sem dadosA coleta falhou para aquele serviço. Nunca é tratado como OK (anti falso-verde).
✅ Ordenação inteligente O painel sempre mostra o Sicoob primeiro, depois os problemas mais antigos — a TV responde à pergunta “tem algo errado agora?” num piscar de olhos.

4 Pré-requisitos

Zabbix Server e Grafana rodando, acesso root e internet. O resto (Python, Chromium, plugins, ícones) o instalador resolve.

ItemRecomendado
CPU / RAM2 vCPU (4 ideal — o Chromium do coletor é pesado) · 4 GB RAM (8 ideal).
Disco10 GB livres.
SistemaDebian 11/12/13, Ubuntu 22.04/24.04 ou família RHEL 8/9.
RedeInternet (apt, PyPI, Chromium) e portas locais 80 (Zabbix UI), 3000 (Grafana), 10051 (trapper).
CredenciaisUsuário da API do Zabbix (Admin) e admin do Grafana.
  1. Confirme que os serviços estão ativos

    systemctl is-active grafana-server zabbix-server — a resposta esperada é active duas vezes.

  2. Anote as credenciais

    URL da API do Zabbix (http://127.0.0.1/zabbix), usuário/senha da API e o admin do Grafana com a senha já trocada do padrão.

5 O que o instalador faz

O install.sh executa 13 etapas — e só termina após verificar tudo (exit 1 se algo falhar). Tudo vai para /opt/downdetector-zabbix/logs/install.log.

#EtapaO que acontece
1DependênciasInstala python3-venv, zabbix-sender, xvfb e bibliotecas do Chromium (apt/dnf).
2ConfiguraçãoPergunta diretório, valida login no Zabbix e no Grafana (3 tentativas), perguntas de cron/kiosk.
3EstruturaCria /opt/downdetector-zabbix com logs/, state/ e screenshots/.
4CópiaCopia coletor, template, config e logos (e normaliza finais de linha CRLF→LF).
5PythonCria venv, instala dependências e o Chromium (Playwright/patchright).
6WrapperGera o run_collector.sh (venv + xvfb-run) usado pelo cron.
7Plugins GrafanaGarante gapit-htmlgraphics-panel e alexanderzobnin-zabbix-app (com --homepath — no Grafana 13 o CLI falha sem ele).
8ProvisionamentoDatasource Zabbix (cacheTTL 5m), os 2 dashboards, 51 ícones e o drop-in de HTML do painel.
9ZabbixImporta o template “Downdetector Monitor” (LLD) e cria o host Downdetector.
10CronAgenda a coleta a cada 5 min (/etc/cron.d/downdetector-zabbix).
11Kiosk opcionalBaixa grafana-kiosk, cria autostart e libera acesso anônimo para a TV.
12Reinicia o GrafanaReinicia uma única vez (plugins/drop-ins/provisioning), esperando o serviço voltar.
13Verificação10 checks (Zabbix, Grafana, dashboards, ícones, venv, cron) — pendências acumulam e o código final é 1.
💡 Reexecutar é seguro Todas as etapas são idempotentes: rodar o instalador de novo reaproveita o que já existe e refaz o que falta. Em caso de falha, corrija a causa e rode de novo.

6 Instalação passo a passo

Do repositório no Windows até o painel no ar — são 3 movimentos: copiar o projeto, responder o instalador e acompanhar as etapas.

6.1 Obter o projeto no servidor

  1. Opção A — clonando o repositório (recomendada)

    No próprio servidor: git clone https://github.com/welissonjunior/ZABBIX-DOWNDETECTOR-V02.git /root/dd-src — o .gitattributes do repo garante finais de linha LF (nada quebra no Linux). Para atualizar depois: git pull e rode o instalador de novo.

  2. Opção B — copiar do Windows (sem git no servidor)

    O instalador usa como fonte a pasta onde ele está — no exemplo, /root/dd-src.

PS> $pw = "SUA_SENHA_SSH"; $srv = "root@IP_DO_SERVIDOR" PS> & "C:\Program Files\PuTTY\plink.exe" -ssh $srv -pw $pw -batch "mkdir -p /root/dd-src" PS> & "C:\Program Files\PuTTY\pscp.exe" -pw $pw -batch -r *.py *.json *.yaml *.sh *.txt *.service logos $srv:/root/dd-src/

6.2 As perguntas do instalador

sudo ./install.sh pergunta — ENTER aceita o padrão; senhas não aparecem ao digitar:

PerguntaResposta do exemplo
Diretório de instalaçãoENTER → /opt/downdetector-zabbix
Zabbix URL · Zabbix usuárioENTER → http://127.0.0.1/zabbix · Admin
Zabbix senhasenha da API do Zabbix
Grafana URL · Grafana usuárioENTER → http://127.0.0.1:3000 · admin
Grafana senhasenha admin do Grafana
Agendar coleta automática (cron)? [S/n]S
Configurar como TV (kiosk)? [s/N]n agora — configure depois (seção 8)
⚠️ Senha errada não passa O instalador valida o login no Zabbix e no Grafana antes de prosseguir (3 tentativas). Se o Grafana ainda usa a senha padrão admin/admin, ele força a troca no primeiro login — troque antes e use a senha nova aqui.

7 Rodando o instalador

No servidor, dentro da pasta do projeto, execute e responda. O banner confirma o início:

root@debian:~# cd /root/dd-src # pasta onde você copiou o projeto root@debian:~# sudo ./install.sh
💡 Modo sem perguntas Em SSH sem terminal interativo (ou com UNATTENDED=1) o instalador usa os valores padrão + variáveis de ambiente — veja o anexo da seção 9. É exatamente o fluxo usado para validar este manual.

Depois das perguntas, as etapas 3 a 12 rodam sozinhas — estrutura, Python/Chromium, plugins, provisioning, Zabbix, cron e semeadura:

9 Verificação final e resumo

A etapa 13 roda 10 checks; com tudo verde o instalador mostra o resumo com as URLs dos dashboards:

O Downdetector NOC - User (/d/downdetector-noc-1?kiosk) mostra os 42 cards com sparkline de 6 h, organizados por categoria, e os KPIs no topo:

12 Verificação pós-instalação — Zabbix

No frontend do Zabbix (http://IP_DO_SERVIDOR/zabbix), o host Downdetector deve aparecer ativo, com 85 itens e dados chegando a cada 5 min:

💡 Serviço novo não aparece no dashboard? O plugin do Grafana cacheia os nomes de métricas — o provisionamento já usa cacheTTL 5m. Espere ~5 min ou reinicie: systemctl restart grafana-server

13 TV / Kiosk

Se respondeu n na pergunta do kiosk, configure depois — rode o instalador de novo e responda S, ou siga a mão:

  1. Teste imediato na máquina ligada à TV

    sudo /opt/downdetector-zabbix/run_kiosk.sh — abre o Wallboard em tela cheia.

  2. Autostart no boot

    Ao aceitar o kiosk, o instalador cria /etc/xdg/autostart/downdetector-kiosk.desktop e baixa o grafana-kiosk para /usr/local/bin — a TV abre sozinha ao ligar.

  3. TV sem login

    O instalador habilita acesso anônimo Viewer no Grafana (drop-in GF_AUTH_ANONYMOUS_*). Verifique com systemctl cat grafana-server | grep ANONYMOUS

  4. Escolher o dashboard da TV

    Por padrão abre o Wallboard. Para o User: KIOSK_DASHBOARD_UID=downdetector-noc-1 run_kiosk.sh

💡 Faixa preta embaixo da tela? É o chrome do navegador/kiosk — o conteúdo usa a altura real do painel (~1870×886 em muitos aparelhos 1080p). O layout se adapta por medição: nada é cortado.

14 Anexo — Instalação sem perguntas (UNATTENDED)

Para automação (Ansible, scripts) — exatamente o fluxo usado para validar este manual na VM de teste:

root@debian:~# sudo UNATTENDED=1 ./install.sh \ --zabbix-url http://127.0.0.1/zabbix \ --zabbix-user Admin --zabbix-pass 'SENHA_ZABBIX' \ --grafana-url http://127.0.0.1:3000 \ --grafana-user admin --grafana-pass 'SENHA_GRAFANA'
FlagEfeito
--no-seedNão roda a coleta inicial (não semeia dados).
--no-cronNão agenda a coleta automática.
--no-kioskNão configura a TV.
--install-dir DIRInstala em outro diretório (padrão /opt/downdetector-zabbix).
-y, --yesResponde “sim” a tudo que for opcional.
SKIP_ZABBIX=1 · SKIP_GRAFANA=1Pula a configuração do Zabbix/Grafana (env).
✅ Sem TTY = modo não-interativo automático Em pipe/SSH sem terminal o instalador detecta e usa os defaults + variáveis de ambiente (ZABBIX_URL/ZABBIX_USER/ZABBIX_PASS, GRAFANA_URL/GRAFANA_USER/GRAFANA_PASS).

15 Anexo — Atualizar depois (deploy do Windows)

Alterou config.json, dashboards ou logos? O ciclo a partir do Windows (PuTTY):

PS> python build_dashboard.py # regenera os 2 dashboards a partir do builder PS> & "C:\Program Files\PuTTY\pscp.exe" -pw $pw -batch .\downdetector_dashboard.json $srv:/etc/grafana/provisioning/dashboards/json/ PS> & "C:\Program Files\PuTTY\pscp.exe" -pw $pw -batch .\downdetector_dashboard_tv.json $srv:/etc/grafana/provisioning/dashboards/json/ PS> & "C:\Program Files\PuTTY\pscp.exe" -pw $pw -batch .\config.json $srv:/opt/downdetector-zabbix/config.json PS> & "C:\Program Files\PuTTY\pscp.exe" -pw $pw -batch .\logos\*.png $srv:/usr/share/grafana/public/img/downdetector/ PS> & "C:\Program Files\PuTTY\plink.exe" -ssh $srv -pw $pw -batch "curl -s -X POST -u admin:SENHA http://127.0.0.1:3000/api/admin/provisioning/dashboards/reload && systemctl restart grafana-server"
⚠️ Adicionou serviços no config.json? São 2 ciclos Envie o config, espere 10–15 s (a LLD cria os itens) e deixe o cron enviar os valores — a 1ª passada após a LLD costuma falhar para as chaves novas.
💡 Restart do Grafana é obrigatório O reload sozinho pode deixar o JS do painel HTML desatualizado — sempre termine com systemctl restart grafana-server.

17 Solução de problemas

Os 8 sintomas mais comuns e o caminho curto para resolver:

SintomaCausa e solução
Tudo “Sem dados” de uma vezColeta falhou por completo (Cloudflare). Veja downdetector.log e rode run_collector.sh --test. Confira patchright, contexto state/pw-profile e as flags WebGL no wrapper.
Painel em branco / plugin desabilitadoGrafana 11+ auto-desabilita plugins no upgrade: Administration → Plugins → habilite gapit-htmlgraphics-panel e alexanderzobnin-zabbix-app → reinicie.
Painel HTML não renderizaFalta o drop-in de sanitização (o instalador cria): systemctl cat grafana-server | grep SANITIZE
Serviço novo não apareceCache de métricas do plugin (cacheTTL 5m): aguarde 5 min ou reinicie o Grafana; lembre dos 2 ciclos de coleta.
Instalação falhou no meioCorrija a causa apontada em logs/install.log e rode o instalador de novo — é idempotente.
Erro de sintaxe “\r” no install.shArquivos editados no Windows com CRLF: dos2unix arquivo (o instalador já normaliza na cópia).
TV mostra “dados desatualizados”Heartbeat parado há mais de 10 min: confira o cron (/etc/cron.d/downdetector-zabbix) e o log do coletor.
Render anônimo mostra shell vazioQuirk do Grafana 13 nesta instância: entre logado (admin) para ver os painéis; a TV usa o kiosk.
⚠️ Cloudflare exige patchright + WebGL Sob Xvfb sem GPU o challenge não passa sem patchright e --enable-unsafe-swiftshader --use-angle=swiftshader (o wrapper já vem assim). Não adicione patches manuais de stealth — conflitam com o patchright.
